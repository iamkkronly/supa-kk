# Notes Taker

A minimal, responsive, Supabase-powered note-taking web app.

## Features

- Supabase auth (signup/login/logout)
- Secure notes storage per user
- Save/load notes from database
- Fully static frontend (HTML/CSS/JS)

## Deploy

1. Clone this repo
2. Add your own Supabase URL and anon key in `supabase.js` if needed
3. Push to GitHub
4. Deploy using GitHub Pages (via settings > pages)
